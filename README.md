# GRE-wordlist
# Vocabloom · GRE 单词花园

鹅黄色与浅绿色主题的极简 GRE 单词学习网页，词库来源为《GRE 词汇精选（乱序版）（6485词）》，包含词汇总量与检索、同义词分组辨析、词根记忆、例句例题、单词闪卡和易错词统计。

学习页与闪卡会按照 A–Z 字母顺序推进，每日目标为 200 词。学习进度、收藏和易错次数会保存在浏览器本地，刷新页面后仍可继续。

每个内置词条都配置了对应的词根拆解、同根词、英文例句和参考译文。同义词页面支持自行新建、编辑和删除组别，也可以在组内自由添加或移除单词；自定义内容同样保存在浏览器本地。

## 本地运行

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000` 即可体验。
